# Project history and attribution

BuzzBridge was completed as an Object-Oriented Programming semester group project. The archived project report lists the original team as:

- Uzma Ahsan
- Mehreen Fatima
- Kausar Fatima

The source in `src/main.cpp` was recovered from the original submission files. The repository organization, CMake file and GitHub-facing documentation were added later.

Because the archive does not reliably separate each member’s individual lines of code, this portfolio edition does not invent an individual contribution breakdown. It should be presented as a **group course project**.
